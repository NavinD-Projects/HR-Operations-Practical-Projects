
# HR Operations Practical Projects

A collection of practical HR projects created to demonstrate foundational knowledge of recruitment coordination, employee database management, Excel reporting, and onboarding documentation.

## 1. Recruitment Tracker – Excel
- Organised candidate details, job positions, and application dates.
- Tracked interview stages and hiring status.
- Used dropdown lists for consistent status updates.
- Created a summary sheet using Excel formulas.

## 2. Employee Database Management – Excel
- Maintained sample employee records, IDs, departments, and designations.
- Organised joining dates and employment details.
- Used filters and dropdown lists for record management.
- Created a department-wise employee summary using Excel formulas.

## 3. Employee Onboarding Checklist – Word
- Prepared a structured employee onboarding checklist.
- Covered pre-joining activities and joining-day formalities.
- Included first-week and first-30-day follow-up activities.
- Organised document verification and onboarding tasks.

## Tools Used

## Skills Demonstrated

- HR Operations
- Employee Data Management

- HR Documentation
